# Mission: 从零写出可运行的 Python 模块（拿 RAG 项目当训练场）

## Why
你已经能照着教程改脚本，但面对空白文件会卡住——缺的不是语法，而是"拿到需求后按什么顺序动手"的方法。你正在做的知识库问答项目（RAG）是你练这套方法的真实场地：把它的每个任务都当成一次"从规格到能跑"的完整练习，做完之后你能独立写出并讲清这类工程，而不是只能改别人写好的代码。

## Success looks like
- 拿到 spec 的任意一个小节，能独立从空文件写出模块骨架，并跑通该节的验收命令
- 能回答"为什么这么写"（为什么先写这个文件、为什么不给这个字段默认值），而不只是"抄得对"
- 在 RAG 剩余任务里，能自己先动手尝试，再对照参考实现找差距

## Constraints
- 起点：只掌握 Python 基础语法，高级语法与工程化概念均不熟悉；讲解需同时覆盖"语法 / 工程概念"与"动手顺序"
- 交流语言：中文
- 教学材料统一放在项目的 `learning/` 目录，不污染代码目录
- 学习方式：边做边学，跟着 RAG 项目走，一个任务讲透一个

## Out of scope
- 系统的 Python 语法教学（本次）
- 算法与计算机基础理论
- 当前任务（T0）之外的其他任务，等 T0 讲透并确认后再开
