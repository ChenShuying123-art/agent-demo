# 起点：会照抄改脚本，从零写会卡

Status: superseded by [[0002-baseline-basic-syntax-only]]

用户自述编程基础为「会照抄改简单脚本」：能看懂语法、能照着例子改到跑起来，但从空白文件开始会卡住。诊断结论是缺的是「动手顺序」这一层，而非语法。

> 注：本条的自我评估后来被 [[0002-baseline-basic-syntax-only]] 修正——"缺的不是语法"这个诊断是错的。

## Implications

- 讲解重点放在"先做什么 → 再做什么 → 每步怎么验证"，而不是逐个语法点。
- 每课必须给出可执行的紧反馈环（一行命令验证），让他自己看到对错。
- 不假设他熟悉工程惯例（配置外置、单例、包入口要轻），遇到时需当场解释 why。
