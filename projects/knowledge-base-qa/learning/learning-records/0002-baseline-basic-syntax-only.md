# 基线修正：只掌握基础语法，未掌握高级语法与工程化概念

用户在课程 0001 之后主动修正了自我评估，实际情况比 LR-0001 中「会照抄改脚本」更基础：**只掌握 Python 基础语法**，对高级语法与工程化概念都不熟悉。

由 T0 代码直接暴露的缺口：

- **语法层**：类型注解（`str` / `list[str]` / `-> str`）、类与继承、`@dataclass` 装饰器、类属性、`from ... import ...` 与 `__name__`
- **工程层**：模块 / 包 / `__init__.py` 的组织、环境变量与 `.env`、配置外置、模块级单例、`logging`、依赖管理（`requirements.txt` / 虚拟环境）

## Implications

- 课程 0001 假设了过多前置知识，需要补一节前置课，并绑定到 T0 的每一行真实代码。
- 后续讲解顺序改为：先拆掉用到的语法 / 工程概念（它解决什么问题）→ 再讲顺序与方法。
- 连"验证命令"本身也要解释（`python -c` 是什么、为什么这样验证）。
- 不得用"这个你应该知道"跳过任何概念。
