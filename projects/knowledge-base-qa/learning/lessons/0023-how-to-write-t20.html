四、两个细节

1. 失败步骤默认展开

<details :open="!step.ok">

成功的步骤折叠起来避免刷屏；失败步骤直接展开，用户第一眼就能看到错误文本。失败项同时加红色边框与红色徽章——颜色不是装饰，是让"异常"在长列表里跳出来。

2. skill 下拉只有「自动」

T26 之前后端 /api/agent/skills 返回空数组，所以下拉只有「自动」。组件不需要特判：v-for 渲染空列表即可，T26 之后自然出现选项。

附：代码全流程拆解

T20 的流程是单向数据流：用户操作 → 子组件 emit → App 发请求 → 结果 props 回传 → 展示组件渲染。网络调用只发生在 App 一处。

阶段代码位置动作
① 页面加载App.vue onMountedapi.agentSkills() 取 skill 列表
② 用户输入AgentPaneltextarea + skill 下拉 + 流式开关
③ 发事件emit('ask', {question, skill, stream})组件不直接请求
④ 调接口App.onAgentAskapi.agentChat 或流式方法
⑤ 回传 props:result="agentResult"答案 + 指标 + steps
⑥ 渲染轨迹ToolTrace逐条 details，失败标红

1. 类型与请求：把后端契约搬到前端

export interface AgentRun {
  answer: string
  skill: string | null
  steps: AgentStep[]
  stop_reason: string
  tool_calls_count: number
  rounds: number
  latency_ms: number
}

agentChat(question: string, skill: string | null): Promise<AgentRun> {
  return request<AgentRun>('/agent/chat', jsonBody({
    question: question.slice(0, MAX_QUESTION_LEN),
    skill,
    history: [],
  }))
}

前端的 AgentRun 与后端 AgentRunOut 字段一一对应；任何一边改字段，另一边都要同步。

2. App：唯一的网络入口

function onAgentAsk(payload: { question: string; skill: string | null; stream: boolean }) {
  void run(async () => {
    if (!payload.stream) {
      agentResult.value = await api.agentChat(payload.question, payload.skill)
      return
    }
    // 流式：先放空结果，随后按事件增量填充
    agentResult.value = { answer: '', skill: payload.skill, steps: [], ... }
  })
}

run() 统一处理 busy 与错误；展示组件只发事件，不关心 ApiError 长什么样。

3. AgentPanel：props 进、emits 出

const props = defineProps<{
  busy: boolean
  result: AgentRun | null
  skills: SkillInfo[]
}>()

const emit = defineEmits<{
  (e: 'ask', payload: { question: string; skill: string | null; stream: boolean }): void
}>()

function submit() {
  const text = question.value.trim()
  if (!text || props.busy) return
  emit('ask', { question: text, skill: skill.value || null, stream: stream.value })
}

单向数据流：子组件不能改 props.result，只能 emit；这样"数据从哪来、在哪改"永远只有一条路径。

4. ToolTrace：失败默认展开

<details :open="!step.ok">
  <summary>
    <span>#{{ step.index + 1 }}</span>
    <span>{{ step.tool }}</span>
    <span :class="['badge', step.ok ? 'ok' : 'bad']">
      {{ step.ok ? '成功' : '失败' }}
    </span>
    <span>{{ step.elapsed_ms }} ms</span>
  </summary>
  <pre>{{ JSON.stringify(step.arguments) }}</pre>
  <pre>{{ step.result_text }}</pre>
</details>

成功步骤折叠省空间，失败步骤默认展开并标红；颜色不是装饰，是让异常在长列表里跳出来。
