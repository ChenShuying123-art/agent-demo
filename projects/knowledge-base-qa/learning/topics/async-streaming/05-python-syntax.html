Python 语法速查（前端视角）

只收这次对话里真正卡住过的语法：缩进、dict、Path、生成器、线程、队列、is None。每条都配一个 JS 对照。

一、最基础的三点

  • 缩进就是代码块，没有 {}，也不用分号。
  • 没有 new：queue.Queue() 直接创建实例。
  • 类型注解可选：def f(x: int) -> str，运行时不做强制检查。

三、函数与参数

def handler(args: dict) -> ToolResult:
    return ToolResult(text="ok")
  • def 定义函数，冒号后缩进。
  • args: dict 是类型注解；-> ToolResult 是返回值注解。
  • 关键字参数：Tool(name="x", description="y")，比 JS 的对象参数更原生。
  • 默认值：def f(limit: int = 50)。
  • 可变参数：*args（位置）、**kwargs（关键字）。

闭包工厂

def _make_handler(settings, spec, remote_name, full_name):
    def handler(args: dict) -> ToolResult:
        ...
    return handler

必须用工厂，不能在循环里直接定义函数，否则所有闭包共享最后一个 spec（晚绑定）。

getattr 与 or 兜底

parameters = (
    getattr(remote, "inputSchema", None)
    or getattr(remote, "input_schema", None)
    or {"type": "object", "properties": {}}
)

getattr(obj, "x", default) 是“取属性，没有就返回默认值”；None or y 会继续用 y。

四、Path(name) 是什么

from pathlib import Path

p = Path("notes.md")     # 只构造对象，不读盘、不建文件
p.name                   # 'notes.md'
p.parts                  # ('notes.md',)
p.is_absolute()          # False
Path("a/b.md").name      # 'b.md'（只保留最后一段）

Path 是 pathlib 的类，Path(name) 是实例化。它跨平台处理分隔符和盘符；真正访问磁盘的是 exists() / write_text() / mkdir()。

在 md_writer/server.py:50 里，它配合 is_absolute()、name、parts 做“只允许纯文件名”的白名单。

五、生成器与 yield

def gen():
    yield 1
    yield 2

g = gen()        # 不执行函数体
next(g)          # 1
next(g)          # 2
next(g)          # StopIteration
  • yield 交出一个值并暂停，保留局部变量和执行位置。
  • for x in gen() 自动处理 StopIteration。
  • 生成器只能遍历一次，不能 len()、不能下标。
  • (x*x for x in xs) 是生成器表达式；[x*x for x in xs] 是列表，立即算完。

六、线程与队列

import queue, threading

events = queue.Queue()          # FIFO、内部带锁

def worker():
    events.put({"event": "step"})
    events.put(None)            # 结束哨兵

t = threading.Thread(target=worker, daemon=True)
t.start()                       # 立刻返回
t.join()                        # 等它结束（可选）

item = events.get()             # 空队列时阻塞
  • target=worker 传函数对象，不能写 worker()。
  • daemon=True：主线程退出时不等它。
  • 一个 Thread 对象只能 start() 一次。
  • 线程里抛异常不会传到主线程，必须自己 try/except 并通知消费者。

七、is None 与 ==

if item is None:
    break

is 比较“是不是同一个对象”，== 比较值。None 是单例，所以判断 None 一律写 is None，PEP 8 也这么要求。

八、循环

for i in range(3):        # 0, 1, 2（不含 3）
    ...

while True:
    ...
    break

range(3) 等价 JS 的 i = 0; i < 3; i++；for x in xs 等价 for (const x of xs)。

十、语法坑清单

  • target=worker()：立刻执行函数，把返回值当 target，启动时报错。
  • 生成器第二次遍历是空的。
  • events.get() 会永远阻塞；生产者必须保证 put(None)。
  • asyncio.run() 不能嵌套在已有事件循环里。
  • 可变默认参数（def f(x=[])）会被所有调用共享，是经典坑。
  • 缩进必须一致；混用 tab 和空格会报 TabError。
