五分钟速查

问题一句话答案
什么是同步阻塞？调用后必须等它返回；等待期间当前线程被占着，干不了别的。
async with 是什么？try/finally 的异步版：进入时 await __aenter__()，退出时 await __aexit__()。
为什么要线程 + 队列？同步 run() 没法中途让出；线程负责“同时”，队列负责“交接”。
生成器是什么？能暂停、按需产出、只能遍历一次的函数；每个 yield 是一帧。
SSE 格式谁定的？外壳（event: / data: / 空行）是 WHATWG 标准；JSON 字段是项目契约。
EventSource 是什么？浏览器自带的 SSE 客户端；只会发 GET，所以本项目改用 fetch + 手写解析。
await 后面为什么排在 setTimeout 前面？微任务队列在下一个宏任务和渲染之前被清空。
GET / POST / PUT？读 / 办事 / 整体替换；POST 不幂等，GET 和 PUT 幂等。
